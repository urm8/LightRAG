Connect MCP

Set LIGHTRAG_API_KEY in the environment that launches your agent, then choose its configuration.

Codex

Add this to ~/.codex/config.toml. env_http_headers reads the key at runtime instead of saving it in the file.

[mcp_servers.lightrag]
url = "{{MCP_URL}}"
startup_timeout_sec = 30
tool_timeout_sec = 300

[mcp_servers.lightrag.env_http_headers]
X-API-Key = "LIGHTRAG_API_KEY"

Cursor

Add this to ~/.cursor/mcp.json (global) or .cursor/mcp.json (project). Launch Cursor where the environment variable is available.

{
  "mcpServers": {
    "lightrag": {
      "url": "{{MCP_URL}}",
      "headers": { "X-API-Key": "${env:LIGHTRAG_API_KEY}" }
    }
  }
}

OpenCode

Add this to ~/.config/opencode/opencode.json or the project opencode.json.

{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "lightrag": {
      "type": "remote",
      "url": "{{MCP_URL}}",
      "oauth": false,
      "headers": { "X-API-Key": "{env:LIGHTRAG_API_KEY}" }
    }
  }
}

Claude Code

Add this server to a project .mcp.json. Claude expands the environment variable when it loads the file.

{
  "mcpServers": {
    "lightrag": {
      "type": "http",
      "url": "{{MCP_URL}}",
      "headers": { "X-API-Key": "${LIGHTRAG_API_KEY}" }
    }
  }
}

OpenClaw

If needed, install OpenClaw and its daemon first using the official quick start.

npm install -g openclaw@latest --allow-scripts=openclaw
openclaw onboard --install-daemon

Register the remote server in OpenClaw's outbound MCP registry, then probe it. Make sure LIGHTRAG_API_KEY is available to the Gateway or daemon, not only your interactive shell.

openclaw mcp set lightrag '{"url":"{{MCP_URL}}","transport":"streamable-http","headers":{"X-API-Key":"${LIGHTRAG_API_KEY}"}}'
openclaw mcp doctor --probe

Keep the API key out of Git. After restarting the client, verify that the query_mixed, search_skills, and save_skill tools are visible.

Install the agent skills

The community skills CLI detects Codex, Cursor, OpenCode, Claude Code, OpenClaw, and other Agent Skills clients.

npx skills add urm8/LightRAG -g
lightrag-agentic-development

Routes text, graph, mixed, and tagged retrieval and keeps repository evidence authoritative.

lightrag-self-learning

Recognizes hard-won golden paths, captures verified procedures in LightRAG, and reuses them later.

For project-local installation, omit -g. To target one client explicitly, append --agent codex, --agent cursor, --agent opencode, --agent claude-code, or --agent openclaw.
